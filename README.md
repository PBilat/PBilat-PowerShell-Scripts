Here are my 4 PowerShell Scripts to get over 300 Files Properties from selected folder (sub-folders will be also scanned)

Steps to do:
1. Create first a new folder under C: with the name Temp (C:\Temp)
2. Start Powershell as administrator
3. You will have to select first your basic folder
4. Then You will be asked to accept the default path and file name for the result
5. Wait until the PS-Script is finished
6. Open MS Excel and import the new created CSV-File

Good luck :-)
